# FixPoint

### School Facility Issue Reporting and Maintenance Management System

FixPoint is a web-based system designed to streamline the reporting, tracking, and management of facility-related issues within a school environment.

It provides separate interfaces for users, facility administrators, and IT administrators to help organize issue reports and maintenance workflows.

## 👥 System Roles

FixPoint provides different interfaces depending on the user's role:

### User

* Report facility issues
* View submitted reports
* Track issue status
* View relevant updates

### Facility Administrator

* Review reported facility issues
* Manage maintenance requests
* Update issue statuses
* Monitor facility-related concerns

### IT Administrator

* Manage system-level functionality
* Monitor IT-related concerns
* Manage administrative operations
